# Memberra for Jellyfin

Production integration between Jellyfin 10.11.x and the Memberra operator platform. It reports health and playback events through a revocable per-server token. It does not receive arbitrary code or shell commands.

Version 1.5 adds complete operator-side account management, including safe username changes alongside provisioning, suspension, restoration, password reset, deletion, library policy and authoritative user inventory.

## Install from the Jellyfin dashboard

1. Open **Dashboard → Plugins → Repositories** in Jellyfin.
2. Add a repository named `Memberra` with this URL:

   `https://raw.githubusercontent.com/MrSynthetic/memberra-jellyfin-plugin/main/manifest.json`

3. Open **Catalog**, install **Memberra**, and restart Jellyfin.
4. Open the Memberra plugin settings and enter the one-time pairing code generated by your Memberra operator account.

Version 1.4.0 is validated against Jellyfin 10.11.11. It adds authoritative user inventory while retaining provisioning, durable event delivery, playback reconciliation, viewer controls and capability negotiation. Older platform or plugin versions remain compatible because protocol additions are optional and unknown capabilities are ignored.

The durable outbox is stored beneath Jellyfin's plugin configuration directory. It is capped at 100,000 events and refuses to delete older undelivered telemetry when full. Corrupt queue entries are quarantined for support inspection rather than silently discarded. Pairing secrets are revocable and the Memberra backend remains the authority for permissions and future command policy.

Version 1.1 also reports active playback/transcode counts, synchronises the non-sensitive library inventory, and includes codec, container, bitrate, dimensions and transcode reasons when Jellyfin exposes them. Remote stopping is opt-in and disabled by default; commands are short-lived, constrained to an active session, acknowledged, audited, and protected against duplicate execution after an acknowledgement failure.

## Build

Run `./build.sh` with the .NET 9 SDK installed.
